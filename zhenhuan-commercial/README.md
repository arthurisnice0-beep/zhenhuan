# 入戏 · 甄嬛传性格小传

## 上传方法

将本文件夹内的文件上传至 GitHub 仓库 zhenhuan 的根目录（与原来的 index.html 同级）。不要把整个 zhenhuan-commercial 文件夹作为外层目录上传。

必须替换：index.html。
必须新增或替换：style.css、app.js、data.js、scoring.js。
保留：.nojekyll、characters/ 内全部20张 JPG。完整压缩包已包含图片，可整体覆盖同名文件。

最终结构：

```
index.html
style.css
app.js
data.js
scoring.js
.nojekyll
README.md
characters/（20张人物图片）
```

无需安装依赖或构建。GitHub Pages 发布后原地址仍为 https://arthurisnice0-beep.github.io/zhenhuan/ 。建议上传全部文件后再刷新网站，避免新旧文件混用。所有图片和代码都使用相对路径，无外部字体、图表或截图服务依赖。
